Social Media App

### امکانات و قابلیت‌های این پروژه:

**1. سیستم احراز هویت (Authentication):**
- ثبت نام (`signup`)
- ورود (`login`)
- خروج (`logout`)

**2. پروفایل کاربری:**
- مشاهده پروفایل دیگران (`profile`)
- ویرایش تنظیمات پروفایل شامل: بیوگرافی، موقعیت مکانی و عکس پروفایل (`settings`)

**3. مدیریت پست‌ها:**
- آپلود پست با عکس و کپشن (`upload`)
- نمایش پست در صفحه اصلی (`index`)
- مشاهده جزئیات یک پست (`post`)

**4. تعامل با پست‌ها:**
- **لایک کردن/آنلایک کردن** پست (`Like_post`)
- **کامنت گذاشتن** روی پست (`comment`)

**5. سیستم فالو و آنفالو:**
- فالو کردن کاربران دیگر (`follow`)
- مشاهده لیست فالوورها و فالوینگ‌ها

**6. صفحه اصلی (فید خبری):**
- نمایش پست‌های کاربرانی که فالو می‌کند
- مرتب سازی تصادفی پست‌ها (با `shuffle`)
- نمایش وضعیت لایک هر پست

**7. سیستم پیشنهاد کاربر:**
- پیشنهاد کاربران جدید برای فالو کردن (سیستم recommendation)

**8. جستجو:**
- جستجوی کاربران بر اساس نام کاربری (`search`)

### خلاصه:
**این یک اپلیکیشن کامل شبکه اجتماعی است که کاربران می‌توانند:**
- ثبت نام و وارد شوند
- عکس آپلود کنند
- پست‌های دیگران را لایک و کامنت کنند
- کاربران دیگر را فالو کنند
- فید شخصی از پست‌های افرادی که فالو می‌کنند ببینند
- پروفایل خود را ویرایش کنند
- کاربران جدید پیدا کنند
